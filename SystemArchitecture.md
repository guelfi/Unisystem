## 🛠️ Tecnologias Utilizadas

### Frontend
- **Angular 21** - Framework principal para interface
- **TypeScript 5.9.3** - Tipagem estática para maior segurança
- **Angular Animations** - Animações nativas do Angular
- **HttpClient** - Cliente HTTP para consumo de API
- **HTTP Interceptors** - Interceptação de requisições para envio de token JWT
- **Route Guards** - Proteção de rotas baseada em autenticação
- **Reactive Forms** - Formulários reativos para cadastro e validação

### Backend
- **.NET Core 8** - Framework principal
- **Entity Framework Core** - ORM para acesso a dados
- **SQLite** - Banco de dados relacional
- **JWT Bearer Authentication** - Autenticação via tokens JWT
- **CQRS Pattern** - Separação de comandos e consultas
- **MediatR** - Implementação do padrão mediator para CQRS
- **FluentValidation** - Validação de dados de entrada
- **AutoMapper** - Mapeamento entre objetos (DTOs e Entities)

### DevOps & Deploy
- **Docker** - Containerização da aplicação
- **Docker Compose** - Orquestração de containers
- **GitHub Actions** - CI/CD automatizado
- **Oracle Cloud Infrastructure** - Hospedagem em nuvem
